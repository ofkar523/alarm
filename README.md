# 교대근무 알람 (안드로이드 앱)

교대 근무 패턴을 입력하면 캘린더에 근무가 표시되고, 근무별 알람 그룹이 휴대폰 알람으로 울리는 앱입니다.
돈 들이지 않고 **GitHub(무료)** 에서 APK 설치 파일을 만들고 배포할 수 있게 구성되어 있습니다. PC에 Android Studio를 깔 필요가 없습니다.

- 휴대폰 알람 기능(AlarmManager)으로 예약하므로 **화면이 꺼져 있거나 앱을 닫아도 울립니다.**
- 잠금 화면 위에 알람 화면이 뜨고, **끄기 / 5분 후 다시** 를 누를 때까지 계속 울립니다.
- 휴대폰을 재부팅해도 알람이 다시 예약됩니다.
- 안드로이드 8.0 이상에서 동작합니다. (아이폰은 지원하지 않습니다)

---

## 1. 준비물

- GitHub 계정 (무료) — https://github.com 에서 가입
- 이 폴더(압축 푼 것)
- 따로 받은 `시크릿_값_비공개.txt` (서명 키 정보)

> ⚠️ `시크릿_값_비공개.txt` 와 `shiftalarm-release.keystore` 는 **절대 저장소에 올리지 마세요.** 둘 다 안전한 곳(클라우드 드라이브 등)에 보관하세요. 잃어버리면 이후 버전을 기존 앱 위에 업데이트할 수 없습니다.

## 2. 저장소 만들기

1. GitHub 오른쪽 위 **+ → New repository**
2. Repository name: `shift-alarm` (아무 이름이나 가능)
3. **Public** 선택 (공개 저장소는 자동 빌드가 무료) → **Create repository**

## 3. 서명 키 등록 (Secrets 4개)

저장소 화면에서 **Settings → Secrets and variables → Actions → New repository secret**

`시크릿_값_비공개.txt` 에 적힌 대로 4개를 하나씩 만듭니다.

| Name | Secret |
|---|---|
| `KEYSTORE_PASSWORD` | 파일에 적힌 비밀번호 |
| `KEY_PASSWORD` | 파일에 적힌 비밀번호 (위와 같음) |
| `KEY_ALIAS` | `shiftalarm` |
| `KEYSTORE_BASE64` | 파일 맨 아래의 아주 긴 한 줄 전체 |

## 4. 파일 올리기

1. 저장소 첫 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**) 클릭
2. 압축 푼 폴더 **안의 내용 전체**를 끌어다 놓기 (`app`, `gradle`, `.github` 폴더와 `build.gradle`, `gradlew` 등)
3. 아래 **Commit changes** 클릭

> `.github` 폴더는 숨김 폴더라 끌어다 놓을 때 빠질 수 있습니다. 올린 뒤 저장소에 `.github` 폴더가 안 보이면:
> **Add file → Create new file** → 파일 이름 칸에 `.github/workflows/build.yml` 입력 → 이 폴더의 같은 파일 내용을 붙여넣기 → **Commit changes**

## 5. 빌드 확인

저장소 위쪽 **Actions** 탭 → **Build APK** 가 돌아갑니다. 처음에는 5~10분쯤 걸립니다.

- 초록색 ✓ 이면 성공 → 실행 기록을 눌러 아래 **Artifacts** 에서 APK(zip)를 받을 수도 있습니다.
- 빨간 ✕ 이면 실패 → 실행 기록을 열어 빨간 단계의 메시지를 복사해 Claude에게 보여 주세요.

## 6. 배포하기 (휴대폰에서 바로 받을 수 있게)

1. 저장소 오른쪽 **Releases → Create a new release**
2. **Choose a tag** 에 `v1.0` 입력 → **Create new tag**
3. 제목에 `교대근무 알람 v1.0` → **Publish release**
4. 몇 분 뒤 그 릴리스 페이지에 `ShiftAlarm-1.0.x.apk` 가 자동으로 첨부됩니다.

이 릴리스 페이지 주소를 다른 사람에게 보내면 누구나 내려받아 설치할 수 있습니다.

## 7. 휴대폰에 설치

1. 휴대폰 브라우저로 릴리스 페이지를 열고 `.apk` 파일을 눌러 다운로드
2. 다운로드한 파일 열기 → "출처를 알 수 없는 앱" 설치 허용 (브라우저 또는 내 파일 앱에 대해 허용)
3. Play 프로텍트 경고가 나오면 **세부정보 → 무시하고 설치**
4. 앱을 열고 근무 패턴을 설정

### 처음 한 번 꼭 할 것
- 알림 **허용**
- 앱의 **설정 탭** 에서 권한 4개가 모두 ✓ 인지 확인 (아니면 "설정 열기"로 허용)
  - 특히 **배터리 최적화 제외** — 삼성 갤럭시는 이걸 안 하면 알람이 늦거나 안 울릴 수 있어요
- **알람 테스트** 를 눌러 소리와 알람 화면 확인
- 갤럭시: 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱이 "절전 상태 앱"에 들어가 있지 않은지 확인

## 8. 업데이트하는 법

1. 화면/기능을 고친 `index.html` 을 저장소의 `app/src/main/assets/index.html` 에 덮어 올리기 (Upload files)
2. 6번처럼 새 릴리스 발행 (태그 `v1.1`, `v1.2` …)
3. 휴대폰에서 새 APK를 받아 설치하면 **기존 앱 위에 업데이트**되고 설정·알람이 그대로 유지됩니다.

## 알아 둘 점

- **알람은 앞으로 45일치가 휴대폰에 예약됩니다.** 앱을 열 때마다 다시 45일로 연장되니, 한 달에 한 번 이상은 앱을 열어 주세요. (설정 탭에 "○월 ○일까지 예약됨"이 표시됩니다)
- 무음/진동 모드여도 알람 음량으로 울립니다. 휴대폰의 **알람 음량** 이 0이면 소리가 나지 않습니다.
- Google Play 스토어에 올리려면 개발자 등록비(1회 25달러)가 들어서 이 안내에서는 GitHub로 배포합니다.
- Google은 출처를 알 수 없는 앱 설치에도 개발자 인증을 요구하는 규정을 나라별로 적용하고 있습니다. 2026년 9월 브라질·인도네시아·싱가포르·태국부터 시작했고, 그 밖의 나라는 2027년 이후 차례로 적용될 예정입니다. 적용되면 무료 "제한 배포 계정"(기기 20대까지) 또는 고급 설치 절차를 써야 할 수 있습니다.

## 폴더 구성

```
app/src/main/assets/index.html   ← 앱 화면 전체 (웹 버전과 같은 파일)
app/src/main/java/...            ← 알람 예약·울림·잠금화면 등 안드로이드 기능
app/src/main/res/raw/*.wav       ← 알람 소리 8종
.github/workflows/build.yml      ← GitHub에서 APK를 자동으로 만드는 설정
```
